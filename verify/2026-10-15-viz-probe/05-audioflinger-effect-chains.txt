# 读法：
#   - "2 effects for session 585" = 自建 AudioTrack 的 Visualizer（加上 PEAK_RMS 测量模式的那个效果）
#   - "1 effects for session 0 / name: Visualizer" = 全局混音上的 Visualizer，就是「音源」模式要用的那条
#   - 轨道音量列 L dB/R dB = -6（= 探针里设的 trackVol 0.5），**没有把媒体音量算进来**：
#     说明媒体音量是在更下游（HAL/DSP）施加的 —— 但这跟"音量 0 时捕获全 0"并不矛盾，
#     Flyme 在 index=0 时显然把混音缓冲本身清掉了（见 03）。
#   - 另一个重要观察：这次 dump 里没有 COMPRESS_OFFLOAD 线程，因为音源是 PCM AudioTrack。
#     长 MP3 会不会走 offload 并因此绕过混音，是还没验证的最大风险（设计文档 §13 P1）。
