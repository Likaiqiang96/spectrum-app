## 顺带修掉的三个 bug

1. **峰值点"满天飞"**：冲高的速率原本取自**归一化后的显示值**，于是自动量程窗口一移动，
   所有柱子一起涨，被误判成"快速上升"，峰值点被反复顶飞。
   改成用**原始 dB 再过 80 ms 包络**算速率（死区 60 dB/s），只认真实瞬态；实测 12 秒后悬浮点 = 0。
2. **菜单被滑动区盖住**：左侧 25% 滑动区正好压在「模式 / 样式」上，点不开；
   现在菜单行那一条、以及子菜单展开时，都优先给菜单。
3. **提示条不显示**：抬手时把 `touchRegion` 清零了，提示条来不及画；改成单独记 `hintRegion`。

